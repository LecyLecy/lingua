# Model

`01_verifikasi_data.ipynb` untuk memeriksa data bersama. Folder `model_a/` dan `model_b/` masing-masing berisi notebook berurutan: preprocessing, perancangan dan pelatihan, evaluasi, lalu test akhir. Semua notebook masih kerangka.

Input berasal dari `data/id_id/`; simpan hasil preprocessing di `data/preprocessed/` sesuai model. Gunakan `dev` untuk evaluasi dan `test` untuk pengujian akhir.
